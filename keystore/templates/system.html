Add / Rotate Key

Adding a key with the same Algorithm + Key ID as an existing active key retires the old one and activates the new one (rotation), preserving history.

For algorithms with a known fixed key width (DMR RC4/Hytera BP: 10 hex chars/40-bit, DES: 16/64-bit, AES-128: 32/128-bit, AES-256: 64/256-bit), a shorter value is zero-padded on the left automatically — e.g. entering 777 for a DMR RC4 key stores it as 0000000777. A value longer than expected is rejected rather than guessed at.
